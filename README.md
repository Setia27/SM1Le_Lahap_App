# 🐝 SM1Le LAHAP — Laporan Harian Pribadi

**SM1Le LAHAP** (*Laporan Harian Pribadi*) adalah aplikasi mobile berbasis Android yang dikembangkan untuk memudahkan Guru dan Tenaga Kependidikan (GTK) di lingkungan **SMAN 1 Lembang** dalam mencatat, mendokumentasikan, dan mencetak laporan kegiatan harian secara cepat dan terstruktur.

## ✨ Fitur Utama

* **🔐 Autentikasi & Manajemen Sesi Aman**
  Login menggunakan NIP/Username dengan fitur *Ingat Saya*, penyimpanan sesi otomatis, serta reset kata sandi mandiri.
* **📝 Pencatatan Kegiatan Harian Real-Time**
  Input nama kegiatan, rentang waktu pelaksanaan, dan uraian tugas yang langsung tersimpan aman di server cloud (**Supabase**).
* **📸 Dokumentasi Foto Otomatis Terkompresi**
  Ambil bukti kegiatan langsung dari kamera dengan kompresi gambar otomatis agar hemat kuota dan penyimpanan.
* **📄 Cetak Laporan PDF Siap Tanda Tangan**
  Ekspor rekap kegiatan harian ke format PDF (pilih periode *Hari Ini*, *Kemarin*, *7 Hari Terakhir*, atau *Rentang Tanggal Kustom*) lengkap dengan lampiran foto dan kolom tanda tangan petugas.
* **👤 Kustomisasi Profil Petugas**
  Perbarui foto profil pengguna secara mandiri langsung dari aplikasi.

## 📥 Cara Instalasi di Android

1. Buka halaman [**Releases Terbaru**](https://github.com/Setia27/SM1Le_Lahap_App/releases/download/v.1.0.2/SM1Le_Lahap_v1.0.2.apk).
2. Unduh file **`SM1Le_Lahap_v1.0.2.apk`** pada bagian *Assets*.
3. Buka file APK yang telah diunduh dan izinkan instalasi dari sumber tidak dikenal (*Install unknown apps*) jika diminta oleh perangkat.
4. Masuk menggunakan **NIP / Username** dan kata sandi yang telah terdaftar.
